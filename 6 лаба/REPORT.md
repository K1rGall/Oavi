# Лабораторная работа №6 (ОАВИ)
## Сегментация текста

### Цель
Реализовать выделение символов в строке текста по горизонтальному и вертикальному проекционным профилям.

### Исходные параметры
- Исходная фраза (кириллица): `ты мне нравишься с каждым днем`
- Фраза для обработки (глаголица): `ⱅⱐ ⰿⱀⰵ ⱀⱃⰰⰲⰻⱎⱑⱄⱔ ⱄ ⰽⰰⰶⰴⱐⰿ ⰴⱀⰵⰿ`
- Шрифт: `Segoe UI Historic` (`C:/Windows/Fonts/seguihis.ttf`)
- Размер шрифта: `96 px`
- Бинаризация: `I(x,y)=1` для черного пикселя, `0` для фона
- Параметры сегментации:
- `MAX_INK_IN_GAP = 2`
- `MIN_GAP_WIDTH = 2`
- `MIN_CHAR_WIDTH = 5`

### 1. Подготовка монохромного изображения (`*.bmp`)
Фраза в глаголице сгенерирована выбранным шрифтом, обрезана по границам текста и сохранена в 1-битный BMP.

![Исходная фраза](output/source/01_phrase_gray.png)
![Монохромное изображение](output/source/02_phrase_mono.png)

Файл BMP: `output/source/03_phrase_mono.bmp`

### 2. Горизонтальный и вертикальный профили
- Горизонтальный профиль: `H(y)=Σ_x I(x,y)`
- Вертикальный профиль: `V(x)=Σ_y I(x,y)`

![Горизонтальный профиль](output/profiles/04_horizontal_profile.png)
![Вертикальный профиль полного изображения](output/profiles/05_vertical_profile_full.png)
![Вертикальный профиль строки](output/profiles/05_vertical_profile_line.png)

### 3. Сегментация символов по профилям с прореживанием
Алгоритм:
- По `H(y)` выделяется строка текста.
- По `V(x)` определяются столбцы-разделители (`V(x) <= 2`).
- Выполняется прореживание коротких разрывов.
- Области между разрывами считаются символами.
- Для каждой области строится ограничивающий прямоугольник `[x1, y1, x2, y2]`.

Результат: обнаружено `25` символов.
