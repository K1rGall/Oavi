# Лабораторная работа №7 (ОАВИ)
## Классификация символов на основе признаков

### Цель
Реализовать посимвольную классификацию сегментированной текстовой строки по признакам, сформировать гипотезы для каждого символа и оценить точность распознавания в базовом и экспериментальном режимах.

### Исходные данные
- Исходная фраза (кириллица): `ты мне нравишься с каждым днем`
- Фраза для обработки (глаголица, uppercase): `ⰕⰠ ⰏⰐⰅ ⰐⰓⰀⰂⰋⰞⰡⰔⰤ Ⱄ ⰍⰀⰆⰄⰠⰏ ⰄⰐⰅⰏ`
- Шрифт строки: `Segoe UI Historic` (`C:/Windows/Fonts/seguihis.ttf`)
- Размеры шрифта:
- Базовый: `96`
- Эксперимент: `104` (`+8`)
- Признаки: `mass_norm`, `center_x`, `center_y`, `mu20`, `mu02`
- Мера близости: `S = 1 / (1 + d)`, где `d` — евклидово расстояние в нормализованном пространстве признаков
- Эталоны классов: `43` символа из `glagolitic_reference_symbols` (`symbols_metadata.csv` + PNG)

### 1. Расчёт меры близости
Для каждого сегментированного символа вычисляется вектор признаков.  
Далее признаки нормализуются по эталонному набору, и вычисляется расстояние до каждого эталона.  
Гипотезы сортируются по убыванию близости `S`.

![Бинаризованная строка (базовый случай)](output/base/base_gray.png)

### 2-3. Гипотезы по каждому символу и вывод в файл
Обнаружено `25` символов (без пробелов).  
Для каждого символа сформировано `43` гипотезы (по числу референсов).

Файл с гипотезами:
- `output/base/base_hypotheses.txt`

```text
3: [('U+2C0F', 0.8559), ('U+2C0A', 0.7939), ('U+2C0B', 0.7885), ...]
```
